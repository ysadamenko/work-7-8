
# GitHubProject

## Опис проєкту

GitHubProject — це навчальний проєкт, створений у середовищі Visual Studio 2022 з використанням мови програмування C#.

## Мета проєкту

Метою проєкту є ознайомлення з системою контролю версій Git та сервісом GitHub.

## Використані технології

- C#
- .NET
- Visual Studio 2022
- Git
- GitHub

## Функціональність

Програма виводить текстові повідомлення у консоль.
